# 🎮 JS GAME 🎮

## Introdução

Este projeto foi desenvolvido como parte do curso "Lógica de Programação: mergulhe em programação com JavaScript" oferecido pela plataforma Alura. O objetivo do curso é ensinar os fundamentos de lógica de programação usando JavaScript, com foco em boas práticas e no desenvolvimento de uma aplicação real.

O desafio final do curso foi criar um jogo interativo chamado **JS GAME**, onde o jogador precisa adivinhar um número secreto gerado pelo sistema.

## Instalação

1. Clone o repositório para a sua máquina local:
   ```bash
   git clone https://github.com/seu-usuario/logica-js-projeto_inicial.git
   ```
2. Acesse o diretório do projeto:

```bash
cd js-game
```
3. Como o projeto é em JavaScript puro (sem necessidade de back-end ou compilação), basta abrir o arquivo index.html no seu navegador.

## Uso
O objetivo do jogo é simples: o sistema gera um número secreto aleatório, e o jogador deve tentar adivinhar qual é esse número. Para jogar:

- Abra o arquivo index.html no seu navegador.
- Insira um número na caixa de texto.
- O jogo informará se o número inserido é maior ou menor que o número secreto.
- Continue tentando até acertar o número!

## Funcionalidades 🔆 
> Interface simples e interativa para adivinhar o número secreto.
> Feedback instantâneo após cada tentativa, indicando se o número inserido é maior ou menor que o número secreto.
> Gerenciamento de tentativas do jogador.
> Resposta final ao acertar o número.

## Tecnologias Utilizadas
- HTML5: Estrutura do jogo.
- CSS3: Estilização da interface.
- JavaScript: Lógica do jogo, incluindo a geração do número secreto e o gerenciamento de tentativas.
